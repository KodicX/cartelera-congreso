# Cartelera del congreso

Cartelera del Congreso PROXY 2026, práctica integradora del Bloque 4 del Taller de Git de KodicX.

Este repositorio es público, pero **nadie del taller tiene permiso de escritura**. La única forma de aportar es con un **fork** y un **pull request** hacia `KodicX/cartelera-congreso`.

## Reglas

1. Trabajas siempre en **tu fork** y en una rama, nunca en `main`.
2. Nadie usa `git push --force`.
3. No se aprueba un PR sin abrir la pestaña **Files changed**.
4. Nadie integra su propio PR.

## Qué hay aquí

| Ruta | Para qué sirve |
|---|---|
| `programa.md` | Programa del congreso: sesiones, sede y horario. |
| `perfiles/` | Un archivo por participante, copiado de `perfiles/_plantilla.md`. |
| `equipos/` | Carpeta de equipos. |
| `CONTRIBUTING.md` | Cómo aportar paso a paso. |

Lee [CONTRIBUTING.md](CONTRIBUTING.md) antes de abrir tu primer pull request.
